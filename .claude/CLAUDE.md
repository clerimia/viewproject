# 项目要求

## 项目基本信息

- **项目名称**：A5-景区导览服务 AI 数字人
- **企业名称**：锐捷网络（苏州）有限公司
- **项目编号**：1093135039

## 项目背景与目标

本赛题旨在利用 AI 数字人技术，构建一个智能、互动、个性化的景区导览服务 AI 数字人，推动文旅服务的智能化升级。

## 功能要求

### 1. 游客交互侧

1. **多模态交互**
   - 支持语音输入和文本输入。
   - 数字人能够以语音、表情和口型同步的方式进行回答。

2. **智能问答与讲解**
   - 能够准确回答关于景区历史、文化、景点特色等常见问题。
   - 能够提供简单的景区讲解。

3. **个性化推荐**
   - 可根据游客兴趣（如“对历史感兴趣”或“喜欢自然风光”）推荐不同的游览路线和讲解重点。

### 2. 管理后台侧

1. **知识库管理**
   - 管理员可上传、更新和维护景区的讲解词、文史资料、常见问题及答案等知识文档，作为数字人的知识基础。

2. **数字人形象管理**
   - 可配置数字人的外观、服装、声音等，使其更贴合景区文化特色。

3. **游客感受反馈**
   - 系统能够分析交互记录，生成游客关注点分析、情感趋势报告及服务建议反馈给管理者。

4. **数据大屏概览**
   - 展示当日/本周服务人次、热门问答、游客满意度趋势等核心运营数据。

## 技术要求

- **AI 模型**：推荐使用开源大模型或其提供的 API 服务。
- **语音技术**：可使用开源方案，例如 ParaTTS、Whisper。
- **数字人引擎**：可使用开源 2D 数字人驱动方案或相关 SDK。

## 资料与知识库要求

## 开发任务清单

### 阶段一：打通检索 → 生成链路（核心闭环）

#### 任务 1：Ai-cust 新建 `RagSearchService`

- **文件**：`com.aicust.service.RagSearchService`
- **内容**：
  - 使用 `RestTemplate` 调用 `http://1.117.74.151:8081/rag/search`。
  - 请求参数传入 `query` 和 `topK`。
  - 解析返回结果中的 `hits` 列表。
  - 将命中的文档内容拼接为文本上下文返回。

#### 任务 2：改造 `AiChatService.streamChat()`

- **文件**：`com.aicust.service.AiChatService`
- **内容**：
  - 构造 system prompt 前，先调用 `RagSearchService` 获取检索结果。
  - 将检索结果作为“参考资料”注入 system prompt。

#### 任务 3：准备景区知识文档并导入 Qdrant

- 编写 5-10 篇景区相关 Markdown 文档，包括：
  - 景区介绍；
  - 各景点讲解词；
  - 历史文化；
  - 游览须知；
  - FAQ。
- 使用脚本调用 RAG 项目的 `POST /api/pipeline/text` 接口批量导入。

### 阶段二：个性化推荐

#### 任务 4：`ChatRequest` DTO 加兴趣标签字段

- **文件**：`com.aicust.dto.ChatRequest`
- **内容**：
  - 新增 `mode` 字段，例如：`history`、`nature`、`food`、`all`。
  - 增加对应 getter/setter。

#### 任务 5：`RagSearchService` 支持分类过滤

- **内容**：
  - 根据 `mode` 拼接 metadata filter。
  - 搜索 Qdrant 时只召回相关分类的文档。

#### 任务 6：前端加兴趣选择

- **文件**：`static/index.html`
- **内容**：
  - 聊天框上方增加模式按钮：历史文化、自然风光、美食特产、综合。
